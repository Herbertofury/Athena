The original source and recoverable history bundle were merged into Athena main through [PR #3](https://github.com/Herbertofury/Athena/pull/3) on 2026-11-10. Four unchanged release files were copied through [PR #21](https://github.com/Herbertofury/Athena/pull/21); the original web ZIP and complete-release ZIP remain outside public Athena.

The derived Athena Build workspace remains separate from this original source and is not included in the current main application build. Full unified application, native runtime and deployment acceptance remain incomplete. Do not delete Feature-Foundry yet.
