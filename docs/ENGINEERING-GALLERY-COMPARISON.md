# Native Media gallery comparison

Athena Media now includes the original Engineering-Atlas draft #9 local JSON comparison and #11 primitive-URL correction as an optional native panel, not an embedded page. `compare.mjs` and `local-compare.mjs` are copied byte-for-byte from preserved source commit `13af2857af303ac54398a88ba965a966331e1e26`. Source-only author identity/privacy review remains in the migration reconciliation record. These are user-owned repository modules, not a new third-party library or license grant. The dated Sodium fixture is a public metadata excerpt, not redistributed image content.

Choose a saved public Modrinth project response and the corresponding retained card. Files are bounded at 2MiB and decoded as strict UTF-8. Comparison checks project identity and ordered HTTPS CDN preview/original URL pairs. Non-string URL arrays, credentials, unsupported hosts/schemes and invalid ports do not become matching. Missing/unsupported data is **unknown**, changed order is **changed**, and matching pairs are **matching**. None of these states verifies authenticity, decoded images, live provider state or full-source completeness.

No network request is made for selection/comparison/download. File names and contents are never added to Media events, local storage, native SQLite or exported receipts. Receipts contain only card ID, exact input digest/byte length and narrow derived result. Explicit downloads are session-only browser object URLs, revoked after use or workspace unmount. Failed reads retain the last completed result; new selections, cancellation and unmount fence late reads/hashes. A fresh workspace starts without retaining the selected local file.

The local database profile may use this offline panel while external image/player controls remain disabled. No provider grant or automatic media loading is introduced. Original standalone source pages are preserved, not independently maintained or deployed.

Verification: original #9/#11 regression tests run against the native modules; a deterministic DOM test checks failed-read recovery and unmount cancellation. The existing real-browser lane exercises the actual file input, matching and malformed URL states, failed-read recovery, downloaded receipt privacy, zero comparison requests, repeated navigation and exact served module hashes. Public-provider playback is a separate gate.
