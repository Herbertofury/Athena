## Guided capstone

### Administer a disposable Azure design

1. Design a disposable resource group with a VM, storage, network and monitoring plan.
2. Write least-privilege role assignments and a private endpoint/DNS validation checklist.
3. Prepare equivalent portal and CLI/PowerShell steps from the current official guide; do not execute paid deployment without budget approval.
4. Define backup, restore, diagnostic and cleanup evidence.
5. In an authorized lab, execute one selected objective and validate it after restart or redeployment.

### Acceptance evidence

- Versioned commands and scope assumptions.
- Actual output for the selected executed objective, or a clear unexecuted label.
- Cost and cleanup verification for any deployed resources.
