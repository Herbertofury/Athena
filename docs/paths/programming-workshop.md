# Programming Workshop: Small Programs, Clear Contracts

Eight connected lessons and two editable Python projects teach values, control flow, functions, identity, validation, structured I/O, tests and delivery.

A practical beginner foundation with two bounded offline projects, not complete programming or job readiness. Starters intentionally fail until implemented; reference tests are separate evidence. No network, credentials, payments or deployment are required.

## Prerequisites

- [Programming: values, control flow and functions](../shared/programming.md)
- [Data structures and algorithmic trade-offs](../shared/algorithms.md)
- [Testing, debugging and release evidence](../shared/testing.md)

## Ordered workshop

1. [Give every value a meaning and a unit](../shared/prog-values-contract.md)
2. [Trace a loop before trusting its output](../shared/prog-trace-control.md)
3. [Build small functions without hidden state](../shared/prog-functions-state.md)
4. [Choose collections from identity and order](../shared/prog-collections-identity.md)
5. [Reject bad input without hiding the reason](../shared/prog-validation-errors.md)
6. [Move structured data through a small command-line program](../shared/prog-files-cli.md)
7. [Make a test distinguish a real mistake](../shared/prog-tests-debug.md)
8. [Finish a small program someone else can verify](../shared/prog-project-delivery.md)

## Offline practice

Download the workshop ZIP from the app, extract it and read its README before running any command. Run commands from that extracted workshop folder. The app does not execute Python or SQL, and a read mark is not lab evidence.

Source and editable exercises: [workshop folder](../../workshops/programming/README.md).
