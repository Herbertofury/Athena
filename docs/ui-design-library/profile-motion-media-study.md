## Exact background behavior and reuse boundaries

### Obsidian Prism: optical UI and finite interaction

- [Source pinned d47c5d9](https://github.com/RMvdesi/obsidian-prism/tree/d47c5d9ccb8886025d0f8b1bdf99bc1b5e4b1d07), GPL-3.0-only. [Host input](https://github.com/RMvdesi/obsidian-prism/blob/d47c5d9ccb8886025d0f8b1bdf99bc1b5e4b1d07/home-ripple-host.js) maps motion to glyph-grid coordinates, gives hover aura, adds short skimmers on fast moves, launches a radial disturbance on primary press, and clears on pointer exit. It excludes chat and interactive controls. [Ripple core](https://github.com/RMvdesi/obsidian-prism/blob/d47c5d9ccb8886025d0f8b1bdf99bc1b5e4b1d07/ripple-core.js) provides a glyph field and horizon layers. [Worker](https://github.com/RMvdesi/obsidian-prism/blob/d47c5d9ccb8886025d0f8b1bdf99bc1b5e4b1d07/src/runtime/ripple-worker.js) and core use a capability probe and worker GPU, main GPU or Canvas2D fallback. The [motion engine](https://github.com/RMvdesi/obsidian-prism/blob/d47c5d9ccb8886025d0f8b1bdf99bc1b5e4b1d07/motion-engine.js) and [vial](https://github.com/RMvdesi/obsidian-prism/blob/d47c5d9ccb8886025d0f8b1bdf99bc1b5e4b1d07/vial-core.js) are separate behaviors; the editable image/video wallpaper is not the ripple renderer.
- Exact reuse requires a compatible GPL distribution and preserving notices/rights; do not pull in installer, host injection or daemon. The author’s attribution of an MIT foundation does not relicense the GPL implementation. For incompatible hosts, implement effects independently and compare recorded output. Tests: consistent input trace for hover/fast move/press/leave, card focus and typing remain untouched, finite waves settle, GPU loss yields usable static/2D fallback, wallpaper opacity/blur/contrast and no hidden video decode.

### Aether: scene renderer, pointer physics and finishes

- [Marketplace](https://hermes-agent.nousresearch.com/marketplace/aether) and [reviewed MIT source at 71129b3](https://github.com/abundantbeing/aether/tree/71129b31958f6378a50ce955951d8ad68014c7ed). Study the pinned `desktop-src` backdrop, pointer, shader, renderer, state and loop files. Do not run host plugin installers, arbitrary model-generated code, Desktop injection or downloaded theme plugins to obtain a background.
- The engine offers 18 curated scenes, 24 engines, ten finishes, scene Auto plus Lens, Ripples, Gravity, Parting, Wind and Off; it smooths position/velocity, caps velocity at 1.4 viewport heights per second, fades the active pointer after 2.2 seconds and uses four 2.4-second click slots. Battery mode suppresses the click rings, not all pointer reaction. The pinned tiers use 12/24/30 FPS and 0.35/0.5/0.75 render scales. Calm caps at 15 FPS and 0.45× configured speed; Still renders a composed frame; hidden views pause. Pointer layers do not intercept host controls.
- Preserve exact code and notices for compatible components; supply only a small host adapter for safe settings, canvas ownership and contrast. Preserve crossfades, finish semantics and independent pointer choice. Measure the brightest moving frame, keep local tokens and readable foreground, and keep the renderer on the user's device with network and remote font loading disabled by default. Report host features not ported; scene parity is not equivalent to every Hermes chat command, imported plugin, font, or account integration.

### ClaudeDevs: source-backed example, not inferred video parity

- The [linked social post](https://x.com/ClaudeDevs/status/2121392666244186327) did not expose its actual video in the research run. The [official Anthropic Theme Examples listing](https://claude.com/marketplace/plugins/theme-examples) points to [Apache-2.0 source pinned at 73c8cf3](https://github.com/anthropics/claude-plugins-official/tree/73c8cf3ea7e296057b467990f2f5d61b4c922260/plugins/theme-examples).
- The exact checked source includes 38 entries, including 18 interactive variants of nine unique scenes. Render contracts live in `hooks/interactive.tsx`, `hooks/scenes/*/{scene.ts,still.ts}`, `hooks/themes.ts` and `hooks/register.tsx`. Host provides pointer state to the shader; move, press and drag are scoped to background margins. An authored still alternative is provided. The example plugin does not distribute the full host runtime. Review component and asset notices and do not claim the missing post or the full proprietary host was reproduced.

## Opera GX: pop out, not a second player

[GX Video Popout](https://www.opera.com/gx/features/video-popout) and [Opera's detailed feature reference](https://help.opera.com/en/latest/features/#video-popout) cover a visible hover affordance, movable/resizable always-on-top window, basic player controls, source return, close without stopping the source, optional opacity and eligible automatic pop-out. A desktop browser owns its chrome; a general website does not. Use [standard video PiP](https://www.w3.org/TR/picture-in-picture/) or, where available, [Document PiP](https://developer.chrome.com/docs/web-platform/document-picture-in-picture). Document PiP can retain custom DOM controls; it is scoped to its opener and does not expose arbitrary window positioning. [Automatic PiP](https://developer.chrome.com/blog/automatic-picture-in-picture-media-playback) depends on browser support, permission, active media and media-session eligibility.

Proof: one media session; position, pause intent, speed, volume and supported captions survive detaching and returning; close returns to the source without duplicate audio; multiple videos/offscreen playback handled explicitly; permission-denied iframe and unsupported hosts use a labeled in-app dock. Ensure visible keyboard/touch controls, a return-to-source path and focus restoration. Do not promise unauthorized embedded playback, always-on-top outside supported hosts or control of DRM.
