# Athena knowledge map

A map is a plan, not a claim of completed teaching. The certificate library is one part of this larger home.

| School | Developed introductions | Next depth targets |
| --- | --- | --- |
| Computing foundations | Hardware, OS processes, files, troubleshooting | Binary representation, CPU/cache architecture, memory, boot, devices, virtualization, Windows administration |
| Networks | IPv4, DNS/DHCP, switching/routing, wireless, transport/TLS | IPv6, VLAN/STP labs, OSPF, route troubleshooting, packet analysis, automation |
| Security | Identity, risk, cryptography, incident response | Secure coding, threat modeling, vulnerability management, logging investigations, governance and authorized defensive labs |
| Coding | Values/functions, algorithms, Git, web, tests, databases | Python/JavaScript projects, types, error handling, APIs, concurrency, performance, accessibility and architecture |
| Cloud & infrastructure | AWS/Azure foundations, IAM, operations, Terraform | Service-specific architectures, versioned IaC labs, resilience tests, cost controls and recovery |
| Linux & platforms | Administration, SELinux, containers, Kubernetes | RHEL 10 practical tasks, storage/network recovery, cluster lifecycle, Helm/Kustomize and operators |
| Data & intelligent systems | Data quality, modeling/DAX, reporting/security | SQL, statistics, probability, visualization, ML evaluation, responsible AI and reproducible analysis |
| Professional craft | Support communication, evidence and portfolios | Technical writing, research methods, planning, ethics, collaboration and interviews |

## Curriculum acceptance rule

A topic is developed only when it has prerequisites, explanation, worked examples, misconception checks, practical work, assessment and source review. A practical skill is verified only when its task has been performed in a suitable environment with retained evidence. No broad “complete” badge should erase remaining gaps.
