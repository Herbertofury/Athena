# Cloud Workshop coverage and gaps

## Included

Eight original lessons cover NIST cloud characteristics and models, shared responsibility, hierarchy/scope, network layers, storage interfaces, idealized scaling, failure-domain headroom, RTO/RPO, a local restore, unit-based cost estimates and pre-change review. Each has six explanatory paragraphs, a worked example, six practice steps, three explained checks, evidence prompts and limits.

Seven commands are deterministic local models. One command performs actual temporary-file copy/restore with digest comparison and cleanup. Fixtures use invented identifiers, timestamps, rates and data. The worksheet offers paper alternatives and a capstone evidence packet. No account, paid service, provider SDK or network target is required.

## Executed versus unexecuted

**Executed locally:** fixed Python calculations/comparisons, boundary/contract tests, synthetic file restore and cleanup. Isolated DOM tests check compatibility and static guide structure; they are not visual or assistive-technology audits.

**Unexecuted real-cloud labs:** account and billing setup, identity authentication and authorization evaluation, resource provisioning, network/DNS/TLS behavior, object/block/file services, load testing, autoscaling events, zone or regional failover, cloud backup restoration, infrastructure-as-code provider planning/apply, monitoring and cleanup/billing verification.

The presence of a provider link does not mean that provider was configured or tested. Models are not vendor emulators. The local restore does not prove cloud durability or application recovery. Every command reports real-cloud execution false.

## What remains outside scope

This is not complete AWS, Azure or Google Cloud training, exam coverage or readiness. Missing areas include hands-on provider interfaces, deep IAM evaluation, managed data services, containers/serverless operations, routing and name resolution details, quotas, compliance evidence, production observability, migration execution, advanced resilience, service-specific pricing and live cleanup verification. There are no official exam questions, score claims, accreditation or job-readiness guarantees.

Current Athena supports one primary check per lesson. This pack contains 24 checks, but the 16 supplemental checks and a dedicated Cloud Workshop route need explicit integration. The original Packet Trail path must remain intact. Nothing in this pack claims publication.

## Environment and source limits

Python 3.12.14/Linux was tested. Python 3.10+ is a design target, not a cross-platform verification claim. The guide is script-free and self-contained, with semantic headings, navigation and expandable answer explanations. No real-browser visual or screen-reader audit was performed.

Fifteen official NIST, AWS, Microsoft and Google documentation sources were opened on 2026-11-07. They support concepts and explicitly attributed vendor examples. The exercise schemas, rates, paths and computations are original teaching choices. Vendor semantics, prices, offers and exam objectives must be checked afresh before a real task. No current provider rate or free-tier offer is used.
