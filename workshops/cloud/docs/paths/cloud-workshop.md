# Cloud Workshop: Reason Locally, Verify Honestly

Eight lessons combine cloud models, responsibility, access boundaries, capacity, resilience, recovery, cost and change review with cost-free local practice.

**Scope:** All provider-side labs are unexecuted. Seven local modeling commands and one actual temporary-file restore build foundation skills, not real-cloud experience, exam readiness or production assurance.

## Before you begin

Basic familiarity with files, programs and a terminal helps. Each lesson explains its terms. You can use a text editor and the paper worksheet if Python is unavailable. The optional executable lab needs Python 3.10 or later; it uses no third-party packages. Tested here on Python 3.12.14/Linux. Other platforms remain unverified.

There are no timers, accounts, administrator permissions or network targets. Predict first, run only the supplied fixed command, then explain the observation. A negative result is often the intended lesson. All real-cloud labs remain unexecuted. Seven commands are local models; one performs an actual temporary-file restore.
