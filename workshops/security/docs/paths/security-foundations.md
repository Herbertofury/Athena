# Security Foundations: Evidence Before Assumptions

Ten connected applied lessons: risk, identity, integrity, boundaries, suspicious requests, patch decisions, logs, response, restore and accountable evidence.

**Scope:** Version-neutral applied beginner practice, not exhaustive Security+ coverage, an official practice exam or proof of job readiness. All fixtures are synthetic. Only the small local file-copy/hash operations are real system operations; no security configuration is changed.

## Start here

No security experience or paid service is required. Basic file and browser familiarity helps. Each lesson explains its terms. You can complete the paper exercises without Python; the optional actual local checks require Python 3.10 or newer. No dependency installation is needed.

Study one lesson at a time. Predict an outcome, perform the safe exercise, then explain the result in your own words. Take breaks; the estimates are not a deadline.
