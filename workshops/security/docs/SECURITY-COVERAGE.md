# Security foundations: coverage and gaps

Reviewed 2026-11-07. This pack is an original applied beginner foundation. It supplements Athena’s six existing Security+ introduction lessons. It is not an exhaustive certification course, vendor training, real exam question bank or professional security assessment.

## Included

Ten lessons, 30 original multiple-choice checks with rationales, six bounded offline commands, a paper-only alternative for every command, an evidence worksheet, a four-inject cumulative tabletop and a self-review rubric. The first check of each lesson matches the existing Athena UI schema. Twenty supplemental checks remain in the lesson documents/data until UI support is deliberately added.

The lesson progression covers:

1. Risk scenarios, confidentiality/integrity/availability, controls and residual risk.
2. Identity, factor categories, least privilege and access lifecycle.
3. Hashing, encryption concepts, HMAC and reference trust.
4. Trust boundaries, flow policies and zero-trust principles.
5. Suspicious requests, verification and nonjudgmental reporting.
6. Vulnerability prioritization, uncertainty and patch/change verification.
7. Synthetic log interpretation, duplicates, time zones and alert limits.
8. Incident decisions, authority, evidence handling and recovery gates.
9. RPO/RTO, backup failure domains and bounded restore evidence.
10. Governance documents, responsibility, changes and evidence quality.

## Real versus simulated

Only a synthetic file write/copy/hash/HMAC check is an actual local systems exercise. Access and flow decisions are pure toy policy evaluation. Vulnerability ordering is a declared teaching rule. Log records and all incident/timing data are invented. No accounts, firewall rules, networks, patches, cloud resources or real backups are changed or tested.

Tests of these fixtures establish the implementation’s specified behavior, not that a learner has mastered the skill. The rubric is not psychometrically validated and cannot estimate an official score or pass probability.

## Important unfinished areas

This is a non-exhaustive gap list, not a verified reproduction of an official blueprint:

- Broader threat-actor, malware, exploit and attack-vector taxonomy with defensive examples.
- Deeper application security, secure development, input/output handling and supply-chain practice.
- Wireless, VPN, secure protocols, endpoint/mobile/IoT/OT and physical security.
- Cryptographic algorithm selection, PKI/certificate lifecycle and practical key-management operations.
- Federation and vendor IAM, real access review, privileged access and session lifecycle.
- Actual firewall/IDS/IPS/EDR/SIEM configuration and authorization-bounded network/security testing.
- Cloud architectures, shared-responsibility details and real platform-specific deployment.
- Data classification and lifecycle depth, privacy/regulatory obligations and vendor evidence review.
- Expanded quantitative/qualitative risk analysis, business impact analysis and real recovery drills.
- Automation, forensics, notification decision procedures and organization-specific playbooks.
- Larger independently reviewed assessments and performance-based tasks without hints.

## Source freshness

Primary sources are linked from every lesson, with retrieval outcomes in the source register. NIST SP 800-61 Revision 3 is used for the current response framing; Revision 2 is not presented as current. Some foundational documents are older and are used for stable concepts, not to claim that every implementation detail is the newest recommendation. RFC 7489 is cited for the limited role of domain authentication, not as a current mail-deployment guide. The Python exercise uses stable standard-library APIs; the executed Python version is recorded in the test evidence.
