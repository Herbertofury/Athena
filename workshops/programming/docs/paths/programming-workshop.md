# Programming Workshop: Small Programs, Clear Contracts

Eight connected lessons and two editable Python projects teach values, control flow, functions, identity, validation, structured I/O, tests and delivery.

**Scope:** A practical beginner foundation with two bounded offline projects, not complete programming or job readiness. Starters intentionally fail until implemented; reference tests are separate evidence. No network, credentials, payments or deployment are required.

## Start here

Use a text editor and Python 3.10 or later. Only the standard library is needed. Tested on Python 3.12.14/Linux; Windows and macOS are not verified. No account, administrator access or network target is required. If Python is unavailable, use the paper exercises; do not claim their execution. Plan roughly six hours for the lessons and additional time to implement both projects.
