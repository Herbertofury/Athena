# CCNA Foundations: Network Decisions and Evidence

Ten original lessons extend Packet Trail into switching control, IPv6, route preference, OSPF, services, wireless and typed automation through fixed offline models.

## Prerequisites

net-packet-journey, net-subnet-planning, net-route-arp, net-dns-evidence, net-dhcp-evidence, net-incident-proof

## Lessons

1. [Separate VLAN membership from successful delivery](../shared/ccnaf-vlans.md)
2. [Explain a loop-free tree without inventing convergence](../shared/ccnaf-loop-control.md)
3. [Check bundle compatibility before promising bandwidth](../shared/ccnaf-bundles.md)
4. [Separate IPv6 address meaning from neighbor discovery](../shared/ccnaf-ipv6.md)
5. [Separate route installation from forwarding lookup](../shared/ccnaf-routing.md)
6. [Check adjacency prerequisites before trusting a path graph](../shared/ccnaf-ospf.md)

10. [Defend a network review with explicit evidence gaps](../shared/ccnaf-capstone.md)

## Work safely

Use the [workbook](../WORKBOOK.md) and [lab guide](../../labs/ccna-workshop/README.md). Complete [coverage and gaps](../CCNA-COVERAGE.md) before interpreting completion.

No equipment, emulator, network traffic, credentials, APIs or configuration changes are used. All device and service validations remain unperformed. Selected conceptual alignment to CCNA 200-301 v1.1 is partial; no complete coverage, exam readiness or production approval is claimed. Cisco states v1.1 through 2027-02-02 and v2.0 from 2027-02-03; this workshop does not map v2.0. Official indexed topics were reviewed, with direct page/PDF retrieval limitations explained in the coverage guide.
