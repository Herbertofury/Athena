# Power BI Concepts and Analytical Reasoning Workshop

Eight connected lessons use fixed local Python teaching models to explain transformations, star filters, calculation context, dates, report design, freshness and hypothetical access without executing Power BI.

## Start safely

Read the [lab guide](../../labs/bi-workshop/README.md), then predict before executing. Use only the supplied fixed wrapper commands. The commands compute synthetic cases in memory. No vendor platform, network or user data is used.

## Lessons

1. [Trace transformations before discussing query folding](../shared/bi-transformations.md)
2. [Declare grain and trace relationship filters](../shared/bi-star-filters.md)
3. [Separate stored row values from filter-context measures](../shared/bi-context.md)
4. [Define time periods before comparing results](../shared/bi-date-reasoning.md)
5. [Design a report with explicit denominators and access needs](../shared/bi-report-design.md)

7. [Separate workspace capability from row visibility](../shared/bi-access-rls.md)
8. [Assemble a bounded analytical handoff](../shared/bi-capstone.md)

## Evidence

Complete the [worksheet](../../labs/bi-workshop/WORKSHEET.md), compare the [answer key](../../labs/bi-workshop/ANSWER-KEY.md), and retain the exact local run outcomes. Paper predictions are a supported alternative, but are not executed evidence.

## Limits

Power BI, Power Query M, DAX, gateways, semantic-model configuration, rendered accessibility and real authorization/RLS are unexecuted. Python results are bounded teaching simulations, not vendor emulation, production readiness, complete objective coverage or exam readiness.
