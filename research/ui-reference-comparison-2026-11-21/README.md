# Five UI design references and when to use them

**Athena research reference · 2026-11-21.** Discovery: [Sean's source list](https://x.com/seanaiux/status/2124148738453389483). The publisher sites, not the post, support the offerings and rights distinctions below. This is a link-only reference, not a template collection or an automated ingestion source. Nothing was installed, purchased, copied, or tested in an application.

## Apply the ideas without changing a project's identity

1. Start with one existing screen. Keep its brand accents and default black theme; improve type hierarchy, spacing, focus and status visibility before adding effects. Use original composition and assets.
2. Keep the existing GameSync Next UI as the default. Put any revised theme behind an explicit opt-in and retain an easy switch back. Theme changes must not change behavior or stored data.
3. On the same screen, check text and control contrast over the darkest and lightest background patches, visible keyboard focus through sticky panels, reduced motion with every action and status still available, and usability at narrow widths. These are review gates, not conformance claims. See [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
