# Scoped historical Engineering-Atlas evidence

These inert snapshots preserve 19 exact historical evidence targets cited by Athena's Engineering wiki. They are not current recommendations, runnable application components, updated security advice, or a replacement for the full preserved source history. Some experiments failed or were rejected; those failures are intentionally retained. Measurements apply only to the documented historical workloads and environments.

## Integrity and provenance

`manifest.json` maps each original pinned source URL to its original Git object and archived files. Each snapshot subtree or individual blob reproduces that original object's Git identity, including file modes. The original source repository remains preserved. This snapshot does not recover expired Actions logs, denied deployment-status records, or never-committed files.

## Scope and reuse

The corpus contains owner-authored experiment source, documentation, test/build logs, sanitized result JSON, and dependency manifests/lockfiles. No provider media, raw provider bodies, model weights, user databases, or credentials are included. Publication is the owner's directed migration, not a grant of a new blanket license or a claim that third-party dependencies are license-free. Dependencies retain their separate upstream licenses. Public provider IDs and test fixtures are evidence, not redistributed assets.

Relative imports and links may refer outside a scoped snapshot. Do not execute these historical candidates or treat this directory as a standalone checkout. Use the preserved full historical repository and its documented prerequisites to reproduce an experiment. No build or application workflow imports this archive.
