# Cloud Workshop: Reason Locally, Verify Honestly

Eight lessons combine cloud models, responsibility, access boundaries, capacity, resilience, recovery, cost and change review with cost-free local practice.

All provider-side labs are unexecuted. Seven local modeling commands and one actual temporary-file restore build foundation skills, not real-cloud experience, exam readiness or production assurance.

## Prerequisites

- [Cloud service models and responsibility](shared-cloud-models)
- [IPv4 addressing and subnetting](shared-ip-subnets)
- [Authentication, authorization and accounting](shared-identity)

## Ordered workshop

1. [Describe the service before choosing the cloud](shared-cloud-model-contract)
2. [Assign responsibility and limit the scope](shared-cloud-responsibility-scope)
3. [Trace access and choose a data interface](shared-cloud-network-storage)
4. [Calculate capacity without inventing elasticity](shared-cloud-capacity-demand)
5. [Check the capacity that survives a failure](shared-cloud-failure-domains)
6. [Measure the recovery gap and verify a local restore](shared-cloud-recovery-objectives)
7. [Forecast usage and keep budget alerts in perspective](shared-cloud-cost-units)
8. [Review a change before calling it a deployment](shared-cloud-change-review)

## Offline practice

Download the workshop ZIP from the app, extract it and read its README before running any command. Run commands from that extracted workshop folder. The app does not execute Python or SQL, and a read mark is not lab evidence.

Source and editable exercises: [workshop folder](https://github.com/Herbertofury/Athena/blob/main/workshops/cloud/README.md).
