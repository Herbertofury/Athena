## Guided capstone

### Build a reconciled sales report

1. Import labs/data/orders.csv and order-lines.csv using synthetic data only.
2. Declare keys and grain; build a relationship rather than duplicating order totals across lines.
3. Create quantity-times-price revenue and verify North=80, South=70, All=150.
4. Build an accessible report with region filtering, clear units and a documented refresh path.
5. Design and test a region access rule in an authorized Power BI environment; hiding a page does not count.

### Acceptance evidence

- Reconciled totals and documented transformation steps.
- Model diagram and measure explanation.
- Actual role-test evidence or a clearly pending security gate.
