## Guided capstone

### Recover a disposable workstation

1. Create a disposable VM using a legitimately licensed or freely available operating system.
2. Inventory virtual CPU, memory, disk, network adapter, boot method and current software version.
3. Create a non-admin lab account and a harmless test document, then back up and restore the document.
4. Diagnose one deliberately misconfigured application setting without disabling security controls.
5. Restart and verify the original user workflow; record rollback and recovered file hash.

### Acceptance evidence

- Hardware/OS inventory and a recoverable baseline.
- Successful restore with content/hash comparison.
- A specific defect, test, repair and repeatable validation.
