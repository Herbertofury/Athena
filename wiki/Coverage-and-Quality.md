## Objective verification limitations

The research register records exact retrieval status. A+/Security+ current objective retrieval remains incomplete, so their mappings are provisional. Network+ uses an issuer-hosted N10-009 PDF baseline whose newest revision/retirement status was not established. Cisco has a documented February 2027 blueprint transition. Microsoft skills are dated; localized timing can differ. Kubernetes exam environments roll forward. Always confirm the exact exam language/date and issuer guide before booking.

## Test evidence

`npm test` covers core calculations, bounded IPv4 properties, policy truth table, data aggregation, progress validation, review scheduling, all seven app views, all 13 credential pages, search/filtering, lesson notes, completion, review and malformed storage recovery. DOM tests use LinkeDOM, not a native browser. Run output must be retained with the exact commit.

Real-browser layout, keyboard/assistive-technology behavior, dialog focus and file import/export downloads require further manual/native-browser validation. The current environment has no supported CUA browser route; no claim of those tests passing is made.
