# Coverage and verification

Reviewed 2026-11-07. This is an introductory release, not the promised end state of exhaustive learning.

## Counts and meaning

- 13 requested credential routes organized.
- 74 paraphrased domain headings recorded as roadmaps. They do not enumerate all official subobjectives.
- 90 original lessons: 40 introductions, eight Packet Trail lessons and 42 workshop lessons.
- 174 original checks across the catalog: 90 primary and 84 supplemental. Five workshop routes account for 126 of these checks.
- 16 worked Python/SQL snippets displayed as literal code. Five downloadable offline packs contain runnable bounded examples, reference tests and unfinished learner projects.
- 13 guided capstone plans. They have not been executed or graded by Athena.
- Four browser-local conceptual tools and three synthetic diagnosis cases. They are not vendor, operating-system or networking emulators.
- Six broader knowledge schools plus professional craft remain growing curricula.

## Objective verification limitations

The research register records exact retrieval status. A+/Security+ current objective retrieval remains incomplete, so their mappings are provisional. Network+ uses an issuer-hosted N10-009 PDF baseline whose newest revision/retirement status was not established. Cisco has a documented February 2027 blueprint transition. Microsoft skills are dated; localized timing can differ. Kubernetes exam environments roll forward. Always confirm the exact exam language/date and issuer guide before booking.

## The Packet Trail expansion

Eight connected applied lessons, three clearly synthetic incident cases, a fixed-table route detective, and a Python loopback HTTP fixture add a coherent practical foundation. The fixture uses fixed synthetic JSON and no user files. Seven pure response tests and eight actual loopback TCP checks, including raw-wire HEAD validation and fixed-JSON method errors are separate from DOM tests. Passing these checks is not learner mastery, a TLS test, or real-browser verification.

## Five applied workshops

Security (10 lessons), Systems (8), Programming (8), Cloud (8) and Data/SQL (8) now have distinct navigation, prerequisites, ordered study and complete source registers. Supplemental checks are deliberately session-only practice; no new mastery score is inferred. Local reference tests demonstrate supplied examples, not independent learner work. Cloud-provider labs and Power BI/DAX/publishing/refresh workflows are unexecuted. No full Security+, A+, RHCSA, cloud-certification or PL-300 coverage is claimed.

## Test evidence

`npm test` covers core calculations, bounded IPv4 properties, policy truth table, data aggregation, progress validation, review scheduling, all eight app views, all 13 credential pages, search/filtering, lesson notes, completion, review and malformed storage recovery. DOM tests use LinkeDOM, not a native browser. Run output must be retained with the exact commit.

Real-browser layout, keyboard/assistive-technology behavior, dialog focus and file import/export downloads require further manual/native-browser validation. The combined workshop staging build did not launch a browser. Its Playwright runner is prepared for authorized CI and fails rather than skipping when the browser is unavailable. Earlier browser receipts from other revisions do not establish acceptance of this new combined build.
