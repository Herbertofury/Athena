## Guided capstone

### Configure and recover a disposable Linux VM

1. Prepare a disposable RHEL 10 training VM through an authorized source and record recovery access.
2. Create a nonprivileged lab user, controlled file permissions and a simple shell script with validation.
3. Inspect service, boot and audit logs; configure one harmless service using supported tools.
4. Practice storage or network changes only after a recoverable snapshot/backup and console path exist.
5. Reboot and verify persistence against the selected EX200 objectives.

### Acceptance evidence

- Exact OS version and selected objective list.
- Before/after command output and successful reboot validation.
- Recovery evidence; browser-only simulation does not count.

## Version and booking notes

- Practical performance exam. Configurations must survive reboot. A browser command simulator alone cannot establish readiness.
- Current page targets RHEL 10. Do not reuse an older RHEL 9 container objective list without a version label.
