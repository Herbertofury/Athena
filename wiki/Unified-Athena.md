# One Athena app

Learning, engineering Research, Media workbench and the local R&D Lab share one shell, contextual search, theme and native in-document navigation. The Lab uses the retained Rust/SQLite engine; on a public static page it explains the local-engine requirement without contacting localhost. This is a **partial public integration**, not a claim that every preserved backend or game feature has moved.
