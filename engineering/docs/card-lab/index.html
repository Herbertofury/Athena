Measurement boundaries

The frame-ready value is a double-requestAnimationFrame scheduling proxy after DOM insertion, not a direct physical-paint measurement. Long Animation Frames and Long Tasks are recorded only if supported. No “instant,” INP, peak-memory or image-decode claim is inferred. Initial generation, serialization, encoding and asynchronous digest timings are outside the render timer and reported separately. The optional worker lane includes startup, structured clone and receiver validation in request-to-ready time. It does not move rendering or incremental sample resets off the main thread. No remote data, images or fonts are loaded. Both variants keep every record and full metadata in the DOM. The last completed equal-output run is retained in memory if a later run fails; download it before reloading.
