# Disposable practice starters

These are original local exercises, not official exam questions. Never target production resources.

- `python/total.py`: implement a validated price calculation. Run `python -m unittest discover -s labs/python` after completing it. The starter intentionally fails until implemented.
- `data/orders.csv` and `data/order-lines.csv`: demonstrate grain and duplicate-total pitfalls. Reconcile the correct order total (150) and line revenue (150) before building visuals.
- `terraform/main.tf`: a local `terraform_data` example. It calls no cloud provider. Review state handling even in local labs. Installing Terraform is optional and not done by the app.

Practice receipts should state versions, exact commands, outputs, failures, recovery and remaining limits.
